# Hookbox

Служба принимает вебхуки на порту 8080. Единая панель управления открывается в браузере или в Windows-приложении Hookbox Manager. По умолчанию панель слушает 127.0.0.1:8081. Для её включения укажи отдельный SHA-256 административного токена в переменной окружения службы `HOOKBOX_ADMIN_SHA256`. Входящие вебхуки используют токены из YAML.

## Первый запуск на Windows

Распакуй архив в постоянную папку. Для Manager требуется Microsoft Edge WebView2 Runtime. Дважды щёлкни `Start Hookbox.cmd`. При первом запуске он создаст `config.yaml` из примера, если файл ещё отсутствует. В консоли появится `Manager sign-in token` для текущего запуска. Если уже задан `HOOKBOX_ADMIN_SHA256`, используй соответствующий ему токен.

Дождись строки `management=true` и оставь консоль открытой. Если запущенный ранее экземпляр занимает порт, закрой его консоль перед повторным запуском. Адрес вебхуков задаётся в `general.host` и `general.port`. Адрес локальной панели по умолчанию — `http://127.0.0.1:8081/`.

Открой `Hookbox Manager.exe` и подключись к локальной панели. Для удалённого сервера укажи HTTPS-адрес его панели. Меню «Локальная служба» управляет службой Windows на этом компьютере.

Для установки службы заверши консольный экземпляр. В PowerShell от администратора выполни следующие команды из каталога с дистрибутивом. Конфигурацию лучше хранить отдельно от исполняемых файлов. Предоставь `NT AUTHORITY\LocalService` чтение и исполнение файлов программы и право изменения в каталоге конфигурации. Право изменять EXE службе не требуется.

```powershell
$admin = .\hookbox.exe --generate-token | ConvertFrom-Json
$admin.token  # Сохрани этот токен для входа в панель службы.
.\install-service.ps1 -ConfigPath 'C:\ProgramData\Hookbox\config.yaml' -AdminSha256 $admin.sha256
Start-Service Hookbox
```

## Linux

Размести бинарник в `/opt/hookbox/hookbox`, конфигурацию в `/etc/hookbox/config.yaml`. Создай системного пользователя и группу `hookbox`. Дай службе право изменять каталог конфигурации для сохранения правок через панель. Сгенерируй ключ командой `/opt/hookbox/hookbox --generate-token`. Добавь хеш в `/etc/hookbox.env` строкой `HOOKBOX_ADMIN_SHA256=<sha256>`, ограничь доступ к файлу. Скопируй приложенный unit в `/etc/systemd/system/hookbox.service`.

```sh
sudo systemctl daemon-reload
sudo systemctl enable --now hookbox
```

## Панель и конфигурация

Открой `http://127.0.0.1:8081/`, введи административный токен. Для удалённой работы опубликуй панель через HTTPS reverse proxy или пробрось порт по SSH. При включённом TLS в `general.ssl` оба встроенных слушателя используют этот сертификат. Адрес панели меняется флагом `--admin-listen`.

Панель редактирует вебхуки, действия, роли, пользователей и токены. В форме действия можно задать команду с отдельными аргументами, рабочий каталог, передачу payload, HTTP-метод, URL и лимиты. Через «Все поля в YAML» доступны также окружение, заголовки и статическое тело. Сначала примени правку в форме, затем нажми «Сохранить конфигурацию». Сервер проверяет YAML и версию файла перед записью. Сохранённые изменения вступают в силу при перезапуске службы.

Существующий YAML поддерживает `${NAME}` в скалярных значениях. Установи переменные в окружении службы перед проверкой `hookbox --config config.yaml --check-config`. Пустой пример не содержит открытых вебхуков. Проверка доступности сервиса — `GET /healthz`.
