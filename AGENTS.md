# Правила разработки

- После каждой итерации добавлять регрессионные тесты на всё поведение, добавленное или изменённое в этой итерации.
- После добавления тестов запускать полный набор регрессионных тестов проекта.
- При ошибках исправлять реализацию или некорректные тесты и повторно запускать полный набор до успешного прохождения.
- Проводить авторевью по необходимости; особо проверять авторизацию, исполнение команд и обработку ошибок.
- Не считать итерацию завершённой без отчёта о полном прогоне тестов и его результате. Явно указывать платформы, на которых проверки не проводились.
